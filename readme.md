# Learn Coding — Katony Technologies

A complete website for learning coding with registration + Iwotago Investment Limited shop.

## Features

- Animated LC icon on hover
- Registration with email verification (4-digit code)
- Shop section for "Iwotago Investment Limited"

## How to use

1. Open `index.html` in any browser.
2. Click "Register Now" to sign up.
3. Enter your name, email, and password.
4. A 4-digit code is sent (check console or real email if EmailJS configured).
5. Enter the code to verify and unlock the shop.
